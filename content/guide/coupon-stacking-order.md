## 순서가 바뀌면 금액이 바뀌어요

쿠폰은 대부분 **앞 단계 금액을 기준으로 계산**돼요. 그래서 상품쿠폰을 먼저 적용하고 카드 할인을 나중에 받아야 할인 총액이 커지는 경우가 많아요. 반대로 포인트를 먼저 쓰면 쿠폰 기준 금액이 줄어 할인 폭이 작아질 수 있어요.

## 기본 순서

1. **상품쿠폰** — 특정 상품에만 적용되는 쿠폰
2. **장바구니·브랜드 쿠폰** — 일정 금액 이상 구매 시
3. **즉시할인·멤버십 할인** — 플랫폼 자체 할인
4. **카드·간편결제 할인** — 결제 수단 선택 단계
5. **포인트** — 마지막에 남은 금액에 적용

> 플랫폼마다 적용 순서가 고정돼 있는 경우도 있어요. 결제 화면에서 '할인 내역'을 펼쳐 실제 적용 순서를 확인하는 게 가장 정확해요.

## 1. 쿠폰은 '중복 가능'인지부터

- **중복 사용 가능**: 상품쿠폰 + 장바구니쿠폰을 같이 쓸 수 있어요
- **택 1**: 비슷한 쿠폰 중 하나만 쓸 수 있어요
- **조건부 중복**: 특정 카드 결제 시에만 다른 쿠폰과 함께 써요

쿠폰함에서 '사용 조건'을 눌러 중복 가능 여부를 먼저 확인하세요. 두 장을 넣어 보고 안 되면 하나씩 빼는 것보다 빠릅니다.

## 2. 최소 구매 금액은 '할인 전' 기준이에요

"3만 원 이상 5,000원 할인"은 대부분 할인 전 금액 기준이에요. 상품쿠폰으로 2만 5천 원이 된 상태에서 5,000원 쿠폰을 넣으면 적용되지 않아요. **금액 조건이 큰 쿠폰을 먼저** 판단하세요.

## 3. 카드 할인은 '실적'을 보세요

전월 실적 조건이 있는 카드 할인은 이번 달 실적이 채워졌는지 확인해야 해요. 실적이 부족하면 할인율이 낮아지거나 적용되지 않아요. 청구 할인(다음 달에 깎아 주는 방식)인지 즉시 할인인지도 구분해서 보세요.

## 4. 포인트는 마지막에, 소멸 예정부터

- 소멸 예정 포인트 → 일반 포인트 순서로 사용
- 1P 미만 잔액은 대부분 사용할 수 없어요
- 적립 포인트는 취소 시 회수되는 경우가 있어요

## 5. 취소·반품할 때를 생각하세요

쿠폰을 써서 산 상품을 취소하면 **쿠폰이 복원되지 않는 경우**가 있어요. 기간이 지나면 재발급도 안 돼요. 큰 할인을 받은 주문은 취소 전에 복원 여부를 확인하세요.

- [ ] 쿠폰 중복 가능 여부 확인
- [ ] 최소 구매 금액(할인 전) 확인
- [ ] 카드 전월 실적 확인
- [ ] 소멸 예정 포인트 먼저 사용
- [ ] 취소 시 쿠폰 복원 여부 확인

## 정리

쿠폰은 **많이 쓰는 것보다 순서대로 쓰는 것**이 중요해요. 결제 화면의 '할인 내역'만 한 번 펼쳐 봐도 새는 돈을 막을 수 있어요.
